Usage
=========
It is always advised to have Steam running in the background. DZGUI is meant to run "on top of" Steam.

DZGUI can be launched in one of three ways.

From a terminal
------------------
Invoke the command ``./dzgui`` from wherever you downloaded DZGUI to.

Launching from a terminal may give more verbose information in the event of a crash, and can be a good way of troubleshooting problems.

From the shortcut shipped with the application
--------------------------------------------------
When completing the first-time setup, you will be asked if you want to create additional system shortcuts.
If applicable for yourDesktop Environment, these shortcuts can be created.

- One shortcut will be located under the ``Games`` category of your system’s applications list/start menu.
- The other is accessed via the ``DZGUI`` shortcut on the desktop

From Steam
--------------
DZGUI will also ask you if you want to add a "non-Steam game" shortcut to Steam.
This shortcut will launch DZGUI directly and comes with integrated grid and cover artwork.

You must restart Steam for this shortcut to take effect in your library.

.. note::
   You can also pass DZGUI launch parameter's to the Steam shortcut via Steam's right-click menu. See :doc:`flags`.
