Command line launch flags
==========================
When run from the terminal, DZGUI provides several flags:

``-d, --debug``: enable developer debugging features. This does not add hidden or extra functionality; it merely enables developers to track deprecation warnings and see values stored in memory.
End-users will gain no benefit from using this flag.

``-m, --map``: check and update system map count value. Unnecessary on most modern systems. If your system does not meet the threshold, the DZGUI setup wizard will prompt you to use this flag.

``-u, --uninstall``: uninstall: granular selection of which state/configuration files to remove.

``-v, --version``: displays the DZGUI version.
